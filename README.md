# Royal Gallery - Vanilla Expansion
A mod based on the vanilla game with the goal of expanding the base game (Founded by Royal_Rotation with art by Royal_Rotation and gfs (Punchline /CB))

# Additions
As of this version, Royal Gallery currently adds
* 27 Jokers
* with way more to come trust

# Dependencies / Installation
- Requires [Steamodded 1018a+](https://github.com/Steamodded/smods/releases)
