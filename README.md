# Royal Gallery - Vanilla Expansion
A mod based on the vanilla game with the goal of expanding the base game (Founded by Royal_Rotation with art by Royal_Rotation, gfs (Punchline /CB), and Muddz)

# Additions
As of this version, Royal Gallery currently adds
* 40 Jokers
* 1 Enhancement
* 1 Tarot
* with way more to come trust

# Dependencies / Installation
- Requires [Steamodded 1814a+](https://github.com/Steamodded/smods/releases)
